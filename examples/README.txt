***************
Example Gallery
***************

This gallery contains short how-to examples and longer tutorials on using ``irispy``.
Each entry is self-contained and explains the concepts it uses.

**We are always looking for more entries, so if you have ideas or code, please do get in touch and we can work on adding it!**

Some lines of code are only there so that the plots and animations render in the online documentation.
They are not needed in notebooks or local scripts.
