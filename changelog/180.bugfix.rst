Metadata properties no longer raise ``TypeError`` when the header lacks their keyword; they return `None`, like the other header properties. This fixes ``observer_radial_velocity`` on real Level 2 files (which have no ``OBS_VR``; rasters now return the per-exposure values), and ``spectral_range``, ``temporal_cadence`` and ``str(meta)`` on the IRIS-aligned AIA cutouts. ``observing_mode_id`` now reads the OBSID from the AIA cutouts' ``DATE_TIME_OBSID`` instead of turning it into one large number.
