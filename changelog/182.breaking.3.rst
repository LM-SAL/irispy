Auxiliary rows with all-zero or non-finite pointing or PC values are interpolated (or, past the first or last good exposure, extrapolated) from the neighbouring exposures, with a warning, and so are the times of exposures with a non-finite time or exposure time. Reading a spectrograph file now raises an error, naming the file (and the spectral window, for a window's WCS), when every auxiliary row of a file is unusable or when the WCS of a window cannot be built. Before, non-finite rows gave NaN coordinates and times (NUV exposures with a non-finite exposure time took their planned start time), a file with all-zero pointing was read with a pointing of (0, 0) arcseconds, and a window whose WCS failed was dropped with a log warning (in a multi-file read, only that file's raster).
