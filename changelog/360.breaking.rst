``irispy.io.read_files`` and ``irispy.io.read_spectrograph_lvl2`` now give each spectral window as one 4D ``SpectrogramCube`` with axes (raster, step, slit, wavelength), one raster for each file, instead of a ``SpectrogramCubeSequence`` of one cube per file; ``SpectrogramCubeSequence`` and ``IRISSequencePlotter`` are removed.
So ``raster["Si IV 1403"][k]`` is still raster ``k``, now a 3D cube, and one raster file, such as a sit-and-stare, has one raster; ``cube.time`` and the per-exposure metadata, such as ``cube.meta["exposure time"]``, have shape (raster, step), and the cube has the header metadata of the first file, with the ``DATE_END`` of the last and, if the first file has no data, the ``XCEN``, ``YCEN`` and ``SAT_ROT`` of the first file with data; ``len`` of a window raises a ``TypeError``, so ``cube.shape[0]`` is the number of rasters, and ``cube.data`` is one array instead of a list of cubes.
