The level 2 readers and cube API changed in several breaking ways. ``read_files`` now always returns a flat ``NDCollection`` with stable product-name keys and reads exactly one observation per call; the typed readers keep their specialized returns. Readers accept ``raw=`` to request unscaled detector values independently of ``memmap``, record the representation in ``meta["scaled"]``, and reject raw values combined with uncertainties. Reduced spatial maps are now native ``NDCube`` objects (spectral products remain ``SpectrogramCube``), symmetric errors are exposed as typed ``uncertainty`` objects, and the red-blue asymmetry error moved from the ``red_blue_asymmetry_error`` key to ``.uncertainty``. ``get_latest_response`` was replaced by ``get_response(observation_time)``, which requires an explicit observation time and gives time-dependent quantities a leading time axis. ``SJICube.apply_dust_mask`` and its undo path were removed in favor of ``mask_dust()`` and ``remove_dust()``, which return new cubes instead of mutating in place. Moment maps are keyed ``summed_intensity`` (or ``integrated_intensity``), ``sigma``, and ``sigma_velocity``, rest wavelengths resolve through one shared policy that records its source in result metadata, and ``density_diagnostic`` now requires ``density_interval`` when the theoretical curve has several monotonic branches and uses the formation temperature only when asked with ``temperature="formation"``. ``SpectrogramCube`` options after ``data, wcs`` are keyword-only, matching ``SJICube``.
