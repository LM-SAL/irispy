With ``memmap=True``, the level 2 readers now give data numbers (DN) with the values of ``memmap=False``: ``cube.data``, ``cube.mask`` and ``cube.uncertainty.array`` are ``dask.array.Array`` that read and scale the file only for the slices that are used. They gave a NumPy memmap of the raw integers of the file, which for slit-jaw cubes were in ``DN_IRIS_SJI_UNSCALED`` with the fill values as 0. Use ``np.asarray(cube.data)`` for a NumPy array.
